## 📖 Hakkında

**ByteBunny**, Go ile geliştirilen, modüler yapısı sayesinde kolayca özelleştirilebilen ve genişletilebilen bir Discord botudur. Sunucunuzun ihtiyaçlarına göre şekillenebilen, hafif ve performanslı bir yapı sunmayı hedefler.

> 🚧 Proje aktif geliştirme aşamasındadır. Katkılarınızı bekliyoruz!

---

## ✨ Özellikler

- 🧩 **Modüler Yapı** — İhtiyacınız olan modülleri kolayca ekleyip çıkarın
- ⚡ **Go ile Yazıldı** — Yüksek performans ve düşük kaynak kullanımı
- 🔓 **Tamamen Açık Kaynak** — Kod tabanını inceleyin, değiştirin, geliştirin
- 🛠️ **Kolay Yapılandırma** — Basit kurulum ve konfigürasyon
- 🌍 **Topluluk Odaklı** — Geliştirme sürecine herkes katkı sağlayabilir

---

## 🚀 Kurulum

```bash
# Depoyu klonlayın
git clone https://github.com/ardayndm/ByteBunny.git
cd ByteBunny

# Bağımlılıkları indirin
go mod download

# Botu derleyin ve çalıştırın
go run ./Bot
```

> Botu çalıştırmadan önce gerekli konfigürasyon dosyalarını (token, prefix vb.) ayarladığınızdan emin olun.

## 🤝 Katkıda Bulunma

ByteBunny, topluluk katkılarıyla büyüyen bir projedir. Katkıda bulunmak için:

1. Bu repoyu **fork**'layın
2. Yeni bir **branch** oluşturun (`git checkout -b ozellik/yeni-modul`)
3. Değişikliklerinizi **commit**'leyin
4. Branch'inizi **push**'layın
5. Bir **Pull Request** açın

Her türlü katkı (kod, dokümantasyon, fikir, hata bildirimi) değerlidir! 🐾
